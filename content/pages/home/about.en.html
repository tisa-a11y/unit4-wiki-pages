What this wiki is for

  • Check what gets built in each room: the plan, drawings and mockups.
  • Report what you find on site so the plan stays right.

How to use it

  • Open a room from the menu to see its plan and drawings.
  • Field notes (bottom of each room page): send one when you measure something, finish a step, find a problem, or need an answer. Add a photo if you can. Tisa and the team read it and update the plan. It goes straight to the shared project inbox.
  • Speak a note (button in the corner): if you’d rather not type, tap it and talk; the note gets sorted for you.
  • If a page and a drawing disagree, stop and ask before building.

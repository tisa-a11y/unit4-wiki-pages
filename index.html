## 7. Routing — where each thing goes
| Came in | Do this |
|---|---|
| **Task** | Look for an existing card first (comment rather than duplicate). Create it in the project's section — Kitchen / Cocina · Bathroom / Baño · Electrical / Electricidad · Laundry / Lavandería · Walls, Molding & Paint · General & HVAC (bedroom, living-dining, hallway, HVAC, building) · New Tasks (need triage) · Backlog · On Hold or Blocked. Re-check section names live before writing. Plain title; description = State / Trade / Next physical action / Governing source (link to SPEC.md). **Unassigned** unless Tisa names someone. |
| **Site fact** | Add to the project's SPEC.md with date and "(John, field)". Comment on the card if it changes one. |
| **Decision needed** | Add a wiki `decisions` doc (`status: open`, priority 1 blocking / 2 next / 3 later). Only Tisa locks. |
| **Locked decision** (`synced: false`) | Update SPEC.md (mark LOCKED), matching cards, the Spanish crew edition, `STATUS-NOW.md`; set `synced: true`. |
| **Field report / session notes** | File facts as above; next steps → unassigned cards; open items → decisions; mark `recorded`. |

Wiki and cards disagree → the wiki wins (never the reverse without Tisa). Any change you make → update `STATUS-NOW.md` in the same pass.
